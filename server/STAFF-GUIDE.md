# راهنمای کارشناس فروش (۱۰ دقیقه)

## ورود
`https://دامنه/account/login/` ← شماره موبایل و رمز. بعد از ورود وارد «داشبورد» می‌شوید (آدرس `/admin/`).
رمز را از «مدیر» بگیرید. ۵ بار رمز غلط = ۱۵ دقیقه قفل.

## ۱) درخواست‌ها (سرنخ‌ها)
هر درخواست مشتری (از دستیار هوشمند یا فرم قیمت) یک کد مثل `Q-1405-0001` دارد و خودکار به یک کارشناس سپرده می‌شود؛ پیام تلگرام/ایمیل هم می‌رسد.
1. «درخواست‌ها و سرنخ‌ها» ← روی کد کلیک کنید.
2. با مشتری تماس بگیرید (شماره قابل کلیک است؛ دکمه واتساپ هم هست).
3. **«ثبت نتیجه تماس»** را بزنید (پاسخ داد / پاسخ نداد / ...). وضعیت «جدید» خودکار «تماس گرفته شد» می‌شود.
4. وضعیت را تا «پیش‌فاکتور ارسال شد» و «موفق/ناموفق» جلو ببرید. یادداشت بگذارید تا بقیه تیم ببینند.
5. اگر درخواست مال کس دیگری است، از «ارجاع» استفاده کنید.
- متن «پیشنهاد دستیار» فقط یک نمونه تصویری بوده، نه طرح یا قیمت؛ قیمت را شما اعلام می‌کنید.

## ۲) تأیید مشتریان ثابت
مشتری ثبت‌نام می‌کند ← داشبورد: «عضویت در انتظار تأیید». «مشتریان» ← نام ← **تأیید عضویت** (فقط مشتری شناخته‌شده را تأیید کنید) یا رد.
تا تأیید نشود، مشتری نمی‌تواند سفارش بدهد.

## ۳) سفارش‌ها
1. «سفارش‌ها» ← کد ← اقلام، شهر، آدرس و فایل‌های مشتری را ببینید (فاکتور یا نقشه).
2. پیش‌فاکتور را PDF کنید و در بخش «ارسال پیش‌فاکتور» بارگذاری کنید ← وضعیت خودکار «پیش‌فاکتور ارسال شد» و مشتری آن را در پنلش می‌بیند.
3. پیام کوتاه به مشتری: «پیام به مشتری» (برای مشتری نمایان است). یادداشت داخلی فقط برای تیم است.
4. وضعیت را به‌روز کنید: بررسی ← تأیید ← ارسال ← تحویل.
- قیمت در سایت نمایش داده نمی‌شود؛ فقط در پیش‌فاکتور شما می‌آید.

## ۴) نکته‌های ایمنی
- فایل‌های مشتری فقط برای کارکنان و صاحب سفارش قابل دانلودند؛ لینک فایل را در جای عمومی نگذارید.
- از رمز ساده یا مشترک استفاده نکنید؛ در پایان کار «خروج» بزنید.
- «خروجی اکسل» اطلاعات تماس مشتری دارد؛ فقط برای کار شرکت و روی سیستم امن نگه دارید.
- مشکل فنی یا گم شدن رمز: به مدیر بگویید (`manage.py reset-password`).
